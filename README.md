 Student Deadline Manager

A Python-based desktop application built using *Tkinter* and *SQLite* designed to help students track assignments, daily tasks, and project progress. It features an interactive dashboard showcasing upcoming deadlines.

 Features
* *Deadline Tracking:* Never miss an assignment due date.
* *Interactive Dashboard:* View urgent tasks at a glance.
* *Local Storage:* Securely manages data locally using an SQLite database.

Built With
* Python
* Tkinter (GUI)
